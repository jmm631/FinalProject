
# CineScope - Movie Explorer

CineScope is a movie exploration web application built using React and the OMDb API. It allows users to search for movies, view movie information, sort results, and save their favorite movies.

## Features

- Search movies by title
- View detailed movie information
- Sort movies by title and release year
- Navigate through movie results using pagination
- Add and remove favorite movies
- Save favorites using localStorage
- Loading indicators and error handling

## Technologies Used

- React
- JavaScript
- CSS
- Vite
- React Router
- OMDb API
- LocalStorage

## API Used

OMDb API: https://www.omdbapi.com/

## Installation and Setup

1. Clone the repository:

   ```bash
   git clone https://github.com/jmm631/FinalProject.git
   ```

2. Open the cloned project folder:

   ```bash
   cd FinalProject
   ```

3. Install the dependencies:

   ```bash
   npm install
   ```

4. Create a `.env.local` file in the project root.

5. Add your OMDb API key:

   ```env
   VITE_OMDB_API_KEY=your_omdb_api_key_here
   ```

6. Start the development server:

   ```bash
   npm run dev
   ```

7. Open the local URL displayed in your terminal.
